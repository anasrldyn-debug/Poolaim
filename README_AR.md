# Pool Aim Live — نموذج أولي

هذا مشروع Java لأندرويد يطلب صلاحية التقاط الشاشة ويضيف طبقة شفافة فوق التطبيقات.

## حدود النسخة الحالية
- لم يتم بناء APK أو اختباره في هذه البيئة.
- الخطوط المعروضة تجريبية وثابتة، وليست ناتجة عن تحليل كرات اللعبة.
- لا يوجد حتى الآن اكتشاف تلقائي للكرات أو حساب فعلي لمسارات التصويب.
- تم تجهيز أساس التقاط الشاشة، لكن تحليل الإطارات لم يُنفذ بعد.

## البناء
يحتاج Android SDK وJDK 17 وGradle. افتح المجلد كمشروع Gradle في Android Studio أو بيئة تطوير أندرويد متوافقة ثم ابنِ نسخة Debug APK.

## الخطوات التالية
قراءة إطارات ImageReader، اكتشاف الطاولة والكرات والجيوب، معايرة الهندسة، حساب نقطة التصادم، ثم رسم المسارات المحسوبة.
